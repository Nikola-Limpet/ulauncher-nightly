# Night Sky

Night Sky is an additional dark theme for this Ulauncher v6 personal fork.
The upstream base is `d01f4804`, version 6.0.0-beta35. Existing themes remain
available. No user settings, installed extensions, or system launcher files were
changed during development; GUI checks used isolated settings and D-Bus sessions.

## Run the checkout

The development environment is already installed in `.venv`. From a terminal:

```sh
cd /home/yuujin/personal/tools/lanir/my-launcher
env -u APPIMAGE -u APPDIR -u ARGV0 make run
```

Leave that terminal running. In another terminal, open the window:

```sh
/home/yuujin/personal/tools/lanir/my-launcher/bin/ulauncher show
```

Click the gear, choose **Color theme → Night Sky**, and reopen the launcher.
That selection is saved as `theme_name` in `~/.config/ulauncher/settings.json`
and is the default for subsequent launches. Other themes remain selectable.

This checkout is v6 beta. Running it with your normal settings stops an existing
v5 instance and runs upstream's v5-to-v6 migration. Back up your Ulauncher settings
and extensions before adopting it for daily use. The development checks did not
perform that migration on your real settings.

On a fresh checkout, use the runtime dependencies listed in CONTRIBUTING.md, then:

```sh
make venv PYTHON_BIN=/usr/bin/python3
.venv/bin/pip install python-xlib
```

The system already supplied GTK3, Cairo, and PyGObject on the tested machine.
Clearing the AppImage variables above is needed when running from the T3 Code
AppImage environment, which otherwise makes Python misidentify its executable.

## Install the built package without replacing the system package

The build produced both a wheel and a source archive in `dist/`.
To install the wheel into this project's existing virtual environment:

```sh
cd /home/yuujin/personal/tools/lanir/my-launcher
env -u APPIMAGE -u APPDIR -u ARGV0 .venv/bin/python -m pip install \
  --no-deps --force-reinstall dist/ulauncher-6.0.0b35-py3-none-any.whl
```

Start the installed copy with:

```sh
env -u APPIMAGE -u APPDIR -u ARGV0 \
  PATH="/home/yuujin/personal/tools/lanir/my-launcher/.venv/bin:$PATH" \
  /home/yuujin/personal/tools/lanir/my-launcher/.venv/bin/ulauncher start
```

Using the checkout with `make run` is sufficient for development; installing the
wheel is optional. Both copies use the same normal Ulauncher settings unless XDG
paths are explicitly overridden.

## Ubuntu Wayland shortcut and startup

With this fork running, open Ubuntu **Settings → Keyboard → View and Customize
Shortcuts → Custom Shortcuts**. Add “Ulauncher Night Sky” with this command:

```text
/home/yuujin/personal/tools/lanir/my-launcher/bin/ulauncher toggle
```

Assign your preferred shortcut, such as Ctrl+Space. Resolve any duplicate binding
from the old launcher. GNOME owns the global shortcut; the theme does not grab keys.

For login startup using the existing `ulauncher.service`, run
`systemctl --user edit ulauncher` and enter:

```ini
[Service]
ExecStart=
ExecStart=/usr/bin/env PATH=/home/yuujin/personal/tools/lanir/my-launcher/.venv/bin:/usr/local/bin:/usr/bin:/bin /home/yuujin/personal/tools/lanir/my-launcher/bin/ulauncher start
```

Then run `systemctl --user daemon-reload` and
`systemctl --user enable --now ulauncher`. If the service is already running,
use `systemctl --user restart ulauncher` to apply the new command. Disable any old
v5 desktop autostart entry to avoid launching both versions at login. These startup
and shortcut changes are instructions only; they were not applied automatically.

## Design and implementation

The sky is a deterministic SVG generated by `data/themes/Night Sky/generate_sky.py`.
Run that script to rebuild `sky.svg`. The SVG contains gradients, blurred cloud
paths, 95 seeded stars, and three small four-point sparkles. GTK renders it at the
window's scale factor. The header occupies 160 logical pixels and ends in black
before the search field. SVG supplies the shapes and soft filters that GTK CSS
alone cannot conveniently express without a custom drawing widget.

The requested palette is retained: purple `#9b5fc0`, primary text `#e6e6e6`,
secondary text `#8a8a8a`, icons `#bdbdbd`, navy `#141a45`, and indigo `#1e1b5c`.
The supplied screenshot showed the old gray launcher, so its desktop wallpaper
was not sampled to replace the requested palette.

Fonts use Inter → Noto Sans → sans-serif for UI, and JetBrains Mono → DejaVu Sans
Mono → monospace for search. No fonts are bundled or downloaded. The sky is static:
there is no twinkle, opening animation, frame loop, or background timer. Compositor
blur is not required. GTK's existing interaction and preferences behavior remains.

GTK named colors are shared in `tokens.css`; geometry stays in theme CSS because
GTK3 does not offer browser-style custom properties for reusable length tokens.
Existing Python spacing values were not rewritten. The shared result-height
calculation now subtracts theme padding to fit the decorative header.

Companion `preferences.css` and `popups.css` files are optional and live beside
assets, outside the selectable CSS glob. Their providers are removed when their
windows close or the selected theme changes. The preferences stylesheet does not
change the desktop's theme preference. A companion `settings.svg` can replace the
launcher gear without changing its action.

## Verification

- Built unmodified upstream first, then built the themed wheel and source archive.
- `make check-all`: 523 tests passed locally and 523 passed in the upstream
  Ubuntu 22.04 / Python 3.8 Docker environment, including lint and type checks.
- Native GTK on headless GNOME Wayland: 1920×1080 at scale 1.
- Native GTK on the connected display: 1440×900 logical, 2880×1800 physical, scale 2.
- Captured and inspected launcher, empty-state, and preferences renders at both scales.
- Exercised search, moving selection down/up, empty query, theme selector persistence,
  switching Night Sky → dark → Night Sky, companion provider cleanup, and concurrent
  launcher/preferences windows with a transparent launcher positioning window.
- Parsed every built-in theme with GTK's CSS provider.

Screenshots are local development artifacts in `.tmp/night-sky/` and are not
packaged. The background is static by construction; no CPU benchmark was performed.
The Docker GUI regression test ran under Xvfb; separate native Wayland probes
covered the real GTK rendering paths.

The upstream package build warns about the test fixture directory
`tests.modes.apps.mock_desktop_entries` missing from package configuration. That
warning also occurred before changes. Isolated D-Bus sessions emitted desktop
portal/service warnings; the headless session additionally logged an unrelated
WezTerm Nautilus extension error. No theme CSS errors occurred in the final checks.

## Boundaries

Application icons retain their original artwork for recognition; only launcher
controls use the new outline artwork. Native semantic error/warning colors remain
where appropriate. There is no separate custom results context menu, toolbar,
search icon, or “no results” panel to redesign. The existing search-entry menu is
covered by popup CSS; an empty query leaves the black search area beneath the sky.
The tray icon belongs to the desktop panel and is unchanged. Preferences retain
their native layout and scrolling behavior. Third-party extension UIs outside
Ulauncher are not restyled.

## Imagegen concept

The built-in imagegen tool produced a preview-only concept, not a shipped bitmap.
Its prompt was:

> Use case: ui-mockup. Preview-only visual concept for Ulauncher Night Sky GTK desktop launcher. Show a single refined rounded 680px-wide launcher on a plain charcoal surround, straight-on UI screenshot composition. Top decorative header about 145px high: deep navy #141a45 and indigo #1e1b5c sky, diffuse purple nebula glow upper right #4b2a7a, sparse small white stars and three tiny four-point sparkles, soft dark blue cloud wisps lower left, smooth fade into absolute black before search field. Below header a black content area, monospace search reading 'terminal', small thin gray search and settings icons. Three compact results with recognizable app icons and secondary gray text; first result 'Terminal' selected in fully rounded muted purple #9b5fc0 pill, white text; other rows 'Files' and 'Settings'. Clean sans serif text, 16px window corners, generous but disciplined spacing, sophisticated quiet atmosphere. No outer headings, no marketing text, no gigantic stars, no neon borders, no glass blur. This is a concept only; actual implementation will use scalable procedural SVG.
